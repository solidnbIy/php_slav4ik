# 👗 Ателье CRM

CRM-система для управления швейным ателье. PHP + MySQL.

## Возможности
- Клиенты (добавление/удаление)
- Заказы (статусы: Новый → В работе → Готов → Выдан)
- Сотрудники и должности
- Материалы и складской учёт
- Платежи и финансы
- Авторизация (оператор / директор)

## Технологии
PHP, MySQL, HTML/CSS, phpMyAdmin
